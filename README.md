# Violet Echo

Demo de novela visual web con selección de personaje, historia ramificada y decisiones con peso.

## Ejecutar localmente

```bash
python -m http.server 80
```

Luego abrir en el navegador:

```text
http://localhost/
```

## Despliegue en Vercel

1. Crear repositorio en GitHub.
2. Subir esta carpeta.
3. Entrar a https://vercel.com.
4. Import Project.
5. Seleccionar el repositorio.
6. Usar la configuración por defecto.
7. Deploy.

La app es estática y no requiere build especial.
